# Coeur / Réseau

Le client de l'API d'`air-service-locator` : créer un compte, déclarer une
machine, lister les services et leur état.

**Vide.** L'API n'est pas spécifiée — elle l'est dans le dépôt serveur,
`docs/protocole.md`, section 2, qui n'en consigne pour l'instant que les
questions ouvertes.

La règle qui gouvernera ce répertoire : **rien ne part d'ici qui ne soit signé
par la clé matérielle de l'appareil** (cf. `../Identite/IdentiteLocale.swift`).
