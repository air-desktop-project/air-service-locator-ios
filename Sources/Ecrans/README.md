# Écrans

Un répertoire par domaine fonctionnel :

| Répertoire | Ce qu'il portera |
|---|---|
| `Compte/` | Création du compte, enrôlement de l'appareil, identifiant public. |
| `Machines/` | Déclarer une machine, la nommer, la retirer. |
| `Services/` | Les daemons d'une machine, leur port, leur état en ligne / hors ligne. |

**Vides.** Aucun de ces écrans n'est dessiné, et les dessiner avant que le modèle
soit arrêté produirait des vues qui décrivent des données supposées.
