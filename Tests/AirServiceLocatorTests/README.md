# Essais

**Vide, et c'est ce qu'il faut dire plutôt que d'y poser un essai qui passe.**

Un essai qui n'éprouve rien rend une suite verte, ce qui est pire que pas de
suite du tout : la première fait croire qu'on mesure quelque chose.

Le premier essai qui aura un sens ici portera sur `IdentiteLocale` — mais il
demande un simulateur, puisque `LAContext` répond selon le matériel.
